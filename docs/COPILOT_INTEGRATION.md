# Copilot Studio

Único orquestador generativo autorizado.

Agentes: orquestador, viabilidad, estrategia, observaciones, documental, candidatos.

Herramientas REST (OpenAPI en `/api/v1/openapi.json`): GetTender, GetCompanyProfile, GetRequirements, SubmitAssessment, etc.

Sin `COPILOT_CONNECTION_STRING` la ejecución no se simula. No se usan agentes públicos para documentos empresariales.
